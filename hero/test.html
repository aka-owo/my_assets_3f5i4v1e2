🔒 HTML暗号化ジェネレータ

保護したいHTMLファイルを選び、パスワードを設定してボタンを押してください。スマホ対応・検索避け完備の暗号化ファイルを生成します。

`; const blob = new Blob([template], { type: 'text/html' }); const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = 'protected.html'; a.click(); URL.revokeObjectURL(url); }
